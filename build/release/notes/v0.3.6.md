## New

### Profiles and sharing

- Share can save an r2modman .r2z file without posting a public code

### Launching and loaders

- Play can start several direct-launch instances of a game, a set delay apart

### Interface and settings

- Settings › About shows the version and the build it came from

## Fixed

- Collapsing the group that holds the open mod keeps it collapsed instead of scrolling back to the mod
- Mod categories and Nexus requirements load while the keyring is locked or missing
- The problem count in the tray and the command line matches the count on the Problems chip
- Reordering list columns keeps a column added while the window was too narrow to show it
- A save's "Last played with" and a crash's Update fix follow profile renames and newly found updates
- README images on a mod's page load
- Download names taken from a link stay inside the downloads folder, and screenshot names Windows cannot store are refused

The Linux AppImage and portable program need glibc 2.38 or newer (Ubuntu 24.04, Debian 13, Fedora 39 or later); older systems use the Flatpak.
