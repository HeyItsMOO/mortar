## New

### Games

- Vintage Story: Mortar finds the copy its installer or Flatpak put in place, browses and installs mods from the Vintage Story Mod DB (and Nexus and GitHub), names each mod from its modinfo.json, and turns them on for the length of each launch
- The Mod DB's 1-click install button can open in Mortar: turn on Handle Vintage Story Mod DB links in Settings › Downloads
- A game no store has art for shows art from its own install
- On Linux, a Windows game outside Steam, such as a copy in a folder you chose or one Heroic or Lutris installed, runs through a Proton version your Steam already has, in a prefix Mortar keeps for it
