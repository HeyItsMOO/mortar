    What is Mortar?

    A free, open source mod manager for Linux, Windows and Steam Deck. It installs each game's mod loader, keeps each set of mods in its own profile and downloads every mod from its own page. How Mortar handles Bopl Battle · Download Mortar

    Everything on this page happens in your browser; the profile is never sent anywhere. Pictures of GitHub and Thunderstore mods load from those sites.
